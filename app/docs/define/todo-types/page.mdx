# Todo types

When you create a todo you have to give it a title.

You can also assign two optional pieces of metadata.

- [Star role](../../concepts/star-roles/page.mdx)
- [Star points](../../concepts/star-points/page.mdx)

A todo with only a title is assumed to be worth `0` star points.

Todos sent to the wayfinder are active items to work on next. You can also optionally send any todo to the database where it is kept for later.
